# بوت عقارات رأس البر (RasElBarBot) 🏖️

بوت تليجرام متطور وفاخر لإدارة وعرض عقارات رأس البر (بيع، إيجار، شاليهات، أراضي). تم تحسين البوت ليكون أكثر كفاءة، أماناً، وسهولة في الاستخدام مع ميزات إدارة متقدمة للمجموعات والقنوات.

## 🚀 المميزات الرئيسية

### 1. واجهة مستخدم فاخرة
- **رسالة ترحيب احترافية**: تصميم جذاب مع رموز تعبيرية وتنسيق احترافي.
- **قائمة تفاعلية**: أزرار منظمة لسهولة التنقل بين جميع الخدمات.
- **تصميم موحد**: تنسيق MarkdownV2 احترافي في جميع الرسائل.

### 2. نظام الحجز الذكي
- **حجز خطوة بخطوة**: توجيه المستخدم لإدخال بياناته بشكل منظم (الاسم، الهاتف، العقار، التواريخ).
- **قاعدة بيانات آمنة**: حفظ جميع طلبات الحجز في SQLite.
- **إشعارات فورية**: إرسال تنبيه للمسؤول بمجرد ورود طلب حجز جديد.

### 3. إدارة المجموعات والقنوات
- **رسالة ترحيب تلقائية**: عند انضمام عضو جديد للمجموعة، يستقبل رسالة ترحيب فاخرة مع روابط مباشرة.
- **كشف الكلمات المفتاحية**: البوت يرد تلقائياً على الرسائل المتعلقة بالعقارات في المجموعات.
- **توجيه ذكي**: جميع الروابط توجه المستخدم مباشرة للبوت لتصفح العروض.

### 4. فصل البيانات عن الكود
- **ملف properties.json**: جميع بيانات العقارات في ملف منفصل لسهولة التحديث.
- **سهولة الصيانة**: يمكن تعديل الأسعار والعقارات دون تعديل الكود البرمجي.

### 5. الأمان والخصوصية
- **متغيرات بيئية**: التوكن ومعرف المسؤول محفوظة في متغيرات آمنة.
- **ملف .env.example**: دليل واضح لإعداد البيانات الحساسة.

## 🛠️ الإعداد والتشغيل

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. إعداد المتغيرات البيئية
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```
TELEGRAM_TOKEN=your_bot_token_here
ADMIN_CHAT_ID=your_admin_chat_id_here
PORT=5000
```

### 3. التشغيل المحلي
```bash
python RasElBarPropertyBot.py
```

### 4. النشر على Render (مجاني)
اضغط على الرابط أدناه لتشغيل البوت تلقائياً:
[Deploy on Render](https://render.com/deploy?repo=https://github.com/wahedelfar/RasElBarBot)
