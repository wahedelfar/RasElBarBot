# بوت عقارات رأس البر (RasElBarBot) 🏖️

بوت تليجرام متطور لإدارة وعرض عقارات رأس البر (بيع، إيجار، شاليهات، أراضي). تم تحسين البوت ليكون أكثر كفاءة، أماناً، وسهولة في الاستخدام.

## 🚀 التحسينات الجديدة

- **فصل البيانات عن المنطق**: تم نقل بيانات العقارات إلى ملف `properties.json` لسهولة التحديث دون تعديل الكود.
- **تحسين الأمان**: استخدام المتغيرات البيئية (Environment Variables) لحماية توكن البوت ومعرف المسؤول.
- **تجربة مستخدم أفضل**: استخدام `ConversationHandler` لعملية حجز منظمة خطوة بخطوة بدلاً من الرسائل العشوائية.
- **تصحيح التنسيق**: معالجة مشاكل MarkdownV2 لضمان ظهور الرسائل بشكل احترافي دون أخطاء.
- **دعم المجموعات**: البوت يتفاعل تلقائياً مع الكلمات المفتاحية في المجموعات للترويج للعروض.

## 🛠️ الإعداد والتشغيل

1. **تثبيت المتطلبات**:
   ```bash
   pip install -r requirements.txt
   ```

2. **إعداد المتغيرات البيئية**:
   قم بإنشاء ملف `.env` بناءً على `.env.example` وأضف بياناتك:
   - `TELEGRAM_TOKEN`: توكن البوت من @BotFather.
   - `ADMIN_CHAT_ID`: معرف التليجرام الخاص بك لاستلام الإشعارات.

3. **تحديث البيانات**:
   يمكنك تعديل `properties.json` لإضافة أو حذف عقارات بسهولة.

4. **التشغيل**:
   ```bash
   python RasElBarPropertyBot.py
   ```

## 📂 هيكلة المشروع

- `RasElBarPropertyBot.py`: الكود المصدري الرئيسي للبوت.
- `properties.json`: قاعدة بيانات العقارات (JSON).
- `bookings.db`: قاعدة بيانات SQLite لتخزين طلبات الحجز.
- `.env.example`: مثال لإعداد المتغيرات البيئية.
